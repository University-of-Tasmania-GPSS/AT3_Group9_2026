# Conclusion/Possible Further Exploration
The analysis process completed in this project is extremely repeatable and can not only be reused for different areas but even for different sized areas (say suburbs instead of LGAs). Our analysis aligned heavily with existing research about crime rates and as such this proves that this analysis provided meaningful insight into crime rates across greater Sydney. This project worked with publicly available data; deeper analysis would be able to occur if we had access to data relating offenders to where they live and what their specific socioeconomic circumstances are. Further hotspot analysis could occur if we had addresses of where crimes occurred. Overall, this project produced a very replicable workflow which produces results which can be used to discuss crime rates throughout an area; however, the data used means that often we are tracking reporting rates rather than actual crime rates.
