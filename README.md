# Project Abstract 
How does the spatial distribution of crime (drug offences, violent crime and property offences) vary across Greater Sydney's Local Government Areas (LGAs), and to what extent is crime rate associated with unemployment, income and high-school completion? 

# Jupyter Book 
https://university-of-tasmania-gpss.github.io/AT3_Group9_2026/

# Organisation of Repositiory 
To replicate the analysis irst use CleaningCrimeData.ipynb to create the associated crime data CSVs then use AT3_patterns_of_crime.ipynb to create the cleaned socio economic data and perform the spatial analysis. Then using the shapefile created in AT3_patterns_of_crime.ipynb, use CorrelationSocio.ipynb to create the correlation analysis results for both socioeconomic factors and time.
